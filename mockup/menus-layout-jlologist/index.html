¿Cómo llega el usuario final a este menú? El LayoutConfigService del layout principal consulta api/configmenu/listar + listar-config-permisos al iniciar sesión; si LAYOUT_ACCORDION='1' dibuja el menú accordion, y ITEMS_VISIBLES (JSON) filtra los módulos.
