### 3. Convertir el Manual a Word

#### Opción 1: Usando Microsoft Word (Recomendado)

1. Abre **Microsoft Word**
2. Ve a **Archivo → Abrir**
3. Selecciona el archivo: `MANUAL_COMPLETO_MODULOS_FRONTEND.md`
4. Word detectará automáticamente que es Markdown
5. El documento se abrirá con formato
6. Ahora inserta las imágenes:
   - Busca cada referencia `![Nombre](./capturas/archivo.png)`
   - Elimina esa línea
   - Ve a **Insertar → Imágenes → Este dispositivo**
   - Selecciona la imagen correspondiente
   - Ajusta el tamaño (recomendado: ancho de página)
   - Agrega pie de foto si es necesario
7. Guarda como `.docx`

#### Opción 2: Usando Google Docs

1. Abre **Google Docs**
2. Crea un nuevo documento
3. Abre el archivo `MANUAL_COMPLETO_MODULOS_FRONTEND.md` con un editor de texto
4. Copia todo el contenido
5. Pega en Google Docs
6. Google Docs convertirá el formato Markdown automáticamente
7. Inserta las imágenes manualmente en las secciones correspondientes
8. Descarga como `.docx`

#### Opción 3: Usando un Convertidor Online

1. Ve a: https://www.markdowntoword.com/
2. Sube el archivo `MANUAL_COMPLETO_MODULOS_FRONTEND.md`
3. Descarga el archivo Word generado
4. Abre el archivo en Word
5. Inserta las imágenes manualmente

### 4. Formato Recomendado en Word

Una vez convertido a Word, aplica estos estilos:

- **Título Principal (H1)**: Arial 24pt, Negrita, Color Azul Oscuro
- **Subtítulos (H2)**: Arial 18pt, Negrita, Color Azul
- **Subtítulos (H3)**: Arial 14pt, Negrita
- **Texto Normal**: Arial 11pt
- **Tablas**: Estilo "Tabla con cuadrícula clara"
- **Imágenes**: Centradas, ancho de página, con borde ligero

### 5. Agregar Portada

Crea una portada profesional con:

```
[LOGO DE LA EMPRESA]

MANUAL DEL SISTEMA DE LOGÍSTICA
Guía Completa de Módulos y Funcionalidades

Empresa: HASS
Versión: 2.0
Fecha: Abril 2026

[Imagen representativa del sistema]
```

### 6. Agregar Índice Automático

En Word:
1. Coloca el cursor después de la portada
2. Ve a **Referencias → Tabla de contenido**
3. Selecciona un estilo automático
4. Word generará el índice basado en los títulos

### 7. Numeración de Páginas

1. Ve a **Insertar → Número de página**
2. Selecciona posición: Parte inferior, centrado
3. Formato: Página X de Y

### 8. Encabezado y Pie de Página

**Encabezado**:
```
Manual del Sistema de Logística | [Nombre del Capítulo]
```

**Pie de Página**:
```
HASS - Sistema de Logística v2.0 | Página X de Y | Abril 2026
```
