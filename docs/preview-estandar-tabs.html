3 · Plantilla HTML estándar (se aplicará en todos los módulos)
<ul class="nav custom-tabs mb-3" role="tablist">
  <li class="nav-item" role="presentation">
    <button
      class="nav-link"
      [class.active]="tabActiva === 'TAB1'"
      (click)="tabActiva = 'TAB1'"
      type="button">
      <i class="bx bx-ICONO me-1"></i> Etiqueta
    </button>
  </li>
</ul>
❌ Patrones INCORRECTOS (se eliminarán)
<!-- MALO 1: <a> + data-bs-toggle hardcoded -->
<a class="nav-link active" data-bs-toggle="tab"
   href="#items" (click)="currentTab='ITEM'">ITEMS</a>

<!-- MALO 2: [class] ternario inline -->
<button [class]="tab==='NI'
  ? 'nav-link active bg-primary text-white'
  : 'nav-link text-primary border...'">

<!-- MALO 3: border-0 en ul / bi bi-* icons -->
<ul class="nav nav-tabs border-0">
  <i class="bi bi-box-seam"></i>
✅ Patrón CORRECTO (nuevo estándar)
<!-- BIEN: button + [class.active] + bx icon -->
<ul class="nav custom-tabs mb-3" role="tablist">
  <li class="nav-item" role="presentation">
    <button
      class="nav-link"
      [class.active]="tabActiva === 'ITEM'"
      (click)="tabActiva = 'ITEM'"
      type="button">
      <i class="bx bx-list-ul me-1"></i>
      Items
    </button>
  </li>
</ul>
