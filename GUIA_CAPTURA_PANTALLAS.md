## 🎯 Instrucciones Rápidas

### Cómo Capturar

1. **Abrir la aplicación**: http://localhost:4200
2. **Loguearse** con el usuario correspondiente
3. **Navegar** al módulo indicado
4. **Presionar** `Windows + Shift + S` para captura parcial
5. **Seleccionar** el área de la pantalla
6. **Guardar** con el nombre exacto en la carpeta `capturas/`

### Consejos

- ✅ Captura solo el área relevante (sin barra de Windows)
- ✅ Asegúrate de que los datos sean visibles
- ✅ Usa el nombre exacto del archivo
- ✅ Formato PNG para mejor calidad
- ✅ Si hay datos sensibles, usa datos de prueba
